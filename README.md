# 🎬 Netflix Clone (HTML & CSS)

A responsive Netflix landing page clone built using pure HTML and CSS.  
This project focuses on UI replication, layout structuring, and responsive design principles.

---

## 📌 Project Overview

This project recreates the front page of Netflix to practice:

- Semantic HTML structuring
- CSS Flexbox & Grid layouts
- Responsive design techniques
- UI replication from a real-world platform

> ⚠️ Note: This is a static UI clone. No backend, authentication, or streaming functionality is implemented.

---

## 🚀 Features

- Responsive navigation bar
- Hero banner section
- Movie/Show thumbnail grid layout
- Hover effects on movie cards
- Fully responsive layout (Mobile + Desktop)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

---

## 📚 What I Learned

- Structuring complex layouts using Flexbox and Grid
- Designing pixel-accurate UI from reference designs
- Managing responsiveness using media queries
- Improving visual hierarchy and spacing

---

## ⚡ Limitations

- No JavaScript functionality
- No dynamic content loading
- No user authentication
- No backend integration

---

## 🔮 Future Improvements

- Add JavaScript for interactivity
- Implement carousel sliders
- Integrate with a movie API (e.g., TMDB)
- Add login/signup functionality
- Convert into a full-stack application
